# LS100 guides

How-to guides from **LS100: Computational Behavioral Sciences** (Harvard University) for working
on this project. Read them in order:

1. [Start your project and submit it with GitHub](01_submitting-assignments-with-github.md):
   create your repository, work in Codespaces, commit, sync, and read the ✓/✗ check.
2. [Running GPU steps in Colab](02_gpu-steps-with-colab.md): run pose estimation or model
   training on a free GPU and bring the results back to your repository.
3. [Make your project portfolio-ready](03_make-it-portfolio-ready.md): turn your finished
   project into something to show employers and graduate programs.

This folder is course scaffolding. You can delete it before sharing your project publicly,
and nothing else depends on it.
